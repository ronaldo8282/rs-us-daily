GitHub 免費自動化更新架設指南 (GitHub Actions + Pages)

步驟 1：建立 GitHub 儲存庫 (Repository)

在 GitHub 建立一個名為 cot-market-report 的公開 (Public) 專案。

步驟 2：建立自動抓取排程 .github/workflows/update_cot.yml

CFTC 每週五下午公佈最新數據。此腳本將在每週六固定抓取並自動更新你的靜態網頁與數據 JSON：

name: Weekly CFTC COT Auto Update

on:
  schedule:
    - cron: '0 8 * * 6' # 每週六 UTC 08:00 (台灣/香港 16:00)
  workflow_dispatch:      # 支援手動一鍵執行

permissions:
  contents: write

jobs:
  update-cot:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install Dependencies
        run: |
          pip install pandas requests

      - name: Fetch CFTC Data & Regenerate JSON
        run: |
          python scripts/fetch_cftc.py

      - name: Commit & Push Changes
        run: |
          git config --global user.name "github-actions[bot]"
          git config --global user.email "actions@github.com"
          git add data/
          git diff --quiet && git diff --staged --quiet || (git commit -m "Automated COT Data Update [skip ci]" && git push)
