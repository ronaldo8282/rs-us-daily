RS90–99 = Percentile ≥ 90 on the as-of Friday. Sector/Industry blank → (unknown). Sector and Industry tables count distinct RS≥90 names in the selected period (This) versus the prior window of the same length (Prior, Δ). MarketCap filter (default off) applies only when MarketCap is known; names with blank mcap stay included when filter is off. WoW adds/drops compare the as-of Friday to the previous Friday column. ΔRS is the change in Percentile; lists sort by the size of that change. Sector counts trend uses the same membership rule on each Friday (Percentile ≥ 90, sector from fundamentals, blank → (unknown)). The window ends at the latest Friday column. Chips show or hide sectors; the number on a chip is that Friday’s count. The top 5 start on. Tickers open TradingView charts in a new tab.
